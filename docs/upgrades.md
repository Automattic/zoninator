# Upgrading

What to check when you update Zoninator. Start with the guide for the version you're updating from, and read each one after it in turn.

| If you're on… | Read |
|---|---|
| 0.12.x | [Upgrading to 1.0](upgrading-to-1.0.md) |
| 0.11.x or earlier | [Upgrading to 0.12](upgrading-to-0.12.md), then [Upgrading to 1.0](upgrading-to-1.0.md) |

No release needs a data migration: your zones and the posts in them carry over unchanged.

For every change in each release, see the [CHANGELOG](../CHANGELOG.md).
